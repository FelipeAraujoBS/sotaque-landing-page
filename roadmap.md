# roadmap.md — Passo a passo do desenvolvimento

Siga esta ordem. Ao concluir cada passo, marque o checkbox abaixo (`[ ]` → `[x]`)
e imprima no console:
```
✅ [ROADMAP] Passo N — <nome do passo> concluído
```
antes de seguir para o próximo. Não pule passos. Detalhes de cada um estão em
`tasks/`.

- [x] **Passo 1 — Setup do projeto** (`tasks/01-setup-projeto.md`)
      Next.js + TypeScript + Tailwind + tokens provisórios + dependências de
      animação instaladas e configuradas.

- [x] **Passo 2 — Hero** (`tasks/02-hero.md`)
      Headline com split-text animado, parallax multi-camada, CTA magnético.

- [x] **Passo 3 — O que fazemos (pilares)** (`tasks/03-pilares.md`)
      Layout assimétrico dos pilares do 360, com entrada animada variada por
      bloco.

- [x] **Passo 4 — Portfólio vivo** (`tasks/04-portfolio.md`)
      Cases filtráveis com transição de layout animada, cursor customizado,
      dados em `content/cases.json`.

- [x] **Passo 5 — Por que Sotaque (DNA regional)** (`tasks/05-dna-regional.md`)
      Narrativa da origem com ritmo de scroll diferenciado e revelação de
      texto por linha.

- [x] **Passo 6 — Depoimentos** (`tasks/06-depoimentos.md`)
      Carrossel com drag real e logos de clientes placeholder.

- [x] **Passo 7 — Instagram embutido** (`tasks/07-instagram.md`)
      Preview do feed via fetch server-side com ISR (ou mock, se sem
      credenciais).

- [x] **Passo 8 — Contato/CTA final** (`tasks/08-contato.md`)
      Formulário com validação animada + botão de WhatsApp magnético.

- [x] **Passo 9 — Performance, SEO e acessibilidade** (`tasks/09-performance-seo-a11y.md`)
      Revisão final: imagens, fontes, metadados, reduced-motion, navegação
      por teclado.

---

## Ao final de tudo

Quando todos os passos estiverem marcados, imprima no console:
```
🎉 [ROADMAP] Demo da landing page Sotaque concluída — 9/9 passos
```
e liste um resumo curto do que ficou como placeholder e precisará ser
substituído quando o time de design entregar os assets finais (referenciar
`docs/design.md`).
